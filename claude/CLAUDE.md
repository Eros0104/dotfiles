# Personal instructions

## Automated PR reviewers

Bot reviewers — Cursor Bugbot, Copilot, SonarCloud, codecov — are input, not correspondents.

- **Never post a reply to a bot review thread.** No "fixed in `<sha>`", no explanation, no disagreement.
- Read them and act on what is valid.
- Resolve a thread once it is dealt with, with no reply attached.
- Report in the session instead: what was real and fixed, what was a false positive and why.
- Human review threads are different — reply to those normally.

## Answering questions

Default to short. One line per question unless asked to expand, and plain language over
implementation detail when the answer is going to a ticket or a teammate.
